# 通用学术措辞（任何领域都适用）

> 领域术语见 `glossary-<domain>.md`。这份只管"怎么把英文论文说得像中文论文"。

## 句式

| 英文 | 别译成 | 译成 |
|---|---|---|
| In this paper, we present X | 在这篇论文中，我们呈现了 X | 本文提出 X |
| We propose / introduce | 我们提议 | 本文提出 / 我们提出 |
| To the best of our knowledge | 据我们所知（可留，别每段用） | 据我们所知 |
| Experimental results show that | 实验的结果展示了 | 实验结果表明 |
| It is worth noting that | 值得注意的是（滥用） | 需要注意 / 值得一提的是 |
| A is superior to B | A 优于 B（可留） | A 优于 B |
| This is because … | 这是因为……（可留，但少用） | 原因在于 …… |
| Moreover / Furthermore / In addition | 此外（三段连续用） | 此外 / 进一步地 / 另外 |
| However | 然而（每段开头） | 然而 / 但 / 不过（换着来） |
| Therefore / Thus / Hence | 因此（全用同一个） | 因此 / 据此 / 可见 |
| Note that | 注意（命令口吻） | 需要注意的是 |
| We argue that | 我们争论 | 我们认为 |
| state-of-the-art | 最先进的（堆砌） | 当前最优 / 已有最优方法 |
| up to N× | 高达 N 倍（满篇"高达"） | 最高 N 倍 / 最多 N 倍 |
| a factor of N | 一个 N 的因子 | N 倍 |

## 硬规则

- **英文缩写首次出现给全称**：`DUT（design under test，被测设计）`，之后只用 DUT 或「被测设计」。
- **数字与单位**：`2.23×`、`571×`、`10 Gbps`、`32 GB` 原样；中英文之间加空格（`RISC-V 处理器`、`2.23 倍`）。
- **引用编号**：保留 `[12]`、`[10], [17]`，不要改写成「文献 12」。
- **图表编号**：`Fig. 2` → `图 2`，`Table I` → `表 I`，`Sec. IV-C` → `第 IV-C 节`，罗马数字保留。
- **标题层级**：论文标题用「：」分隔主副标题；节标题不加句号；子节标题首字母大写与否跟原文。
- **不要出现**："如下图所示"（没有图时）、"笔者"、"我们可以看到"、"众所周知"、"毫无疑问"、"赋能"、"抓手"、"闭环"（除非原文确实是 closed loop）。
- **不要总结**：原文一句话就是一个信息点，删了就是漏译。
- **保留作者语气**：原文用 "we" 就是「我们」，原文用被动就尽量保持客观，不要改成"笔者"。

## 数字/单位/符号

- 千分位：`30,000` 保留逗号；中文里也可写 `3 万`，但**同一篇里统一**。
- 范围号：`2–4`（短横/连接号），不要用 `~`。
- 乘号：`×` 不是 `x`；减号 `−` 不是连字符。
- 百分号：`19.3%`（半角 %，数字前不加空格）。
- 温度/频率/容量：`100 MHz`、`16 GB` 中间空格。
